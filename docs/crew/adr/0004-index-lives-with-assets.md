# ADR 0004：索引放在素材文件夹里，不放在工作目录里

**决定。** 素材索引写在 `<素材文件夹>/.narrate-index.json`。

**衡量过的选项。**

1. 放素材文件夹里（选了这个）。
2. 放当前视频的工作目录里。
3. 放用户主目录下一个全局位置。

**为什么选它。**

理解一段视频要花时间和钱。一份索引应该给以后的每一条视频用。选项 2 会让每做一条新视频就把所有素材重新理解一遍——这直接违反 PRD 的 `F-2`。

选项 3 能复用，但会碰到一个麻烦：用户把素材文件夹整个搬到外部硬盘或另一台机器上，索引就留在了原处，等于白做。放在素材旁边，搬走的时候索引一起走。

**代价。** 索引文件会出现在用户的素材文件夹里。用点号开头（`.narrate-index.json`）让它在文件管理器里默认隐藏，并在 `.gitignore` 的建议里提一句。另外一个素材同时属于两个文件夹（比如软链接）时会有两份索引——这种情况少见，暂不处理。
