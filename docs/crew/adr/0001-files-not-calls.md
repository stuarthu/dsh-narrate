# ADR 0001：模块之间用文件说话，不用函数调用

**决定。** 五个阶段之间不互相调用。每个阶段读上一个阶段写的文件，写自己的文件。

**衡量过的选项。**

1. 文件传递（选了这个）。
2. 阶段之间直接函数调用，状态放内存。
3. 消息队列。

**为什么选它。**

第一个理由是本项目的特殊处境：造这个系统的工程师之间完全不能说话。任何两个模块必须先约定的东西，只能写成文件格式，否则根本不会被约定。选项 2 让约定藏在函数签名里，两侧各写一半就一定对不上。

第二个理由和产品直接相关。产品的核心卖点是**四个停点**——用户要看到每一步的产物。产物本来就得是文件。既然要写文件给人看，再另建一条内存通道就是白做一遍。

第三个理由是修改成本。任何一步不满意，改那一个文件重跑下一步就行。选项 2 里改一步等于整条重跑。

**代价。** 每个阶段要多做一次读文件和写文件，一条视频大约多几十毫秒。相比配音和渲染的耗时，可以忽略。另外文件格式变化要两侧一起改，比改一个函数签名麻烦——这个代价是故意付的，因为它逼着约定被写下来。
