# dsh-narrate

版本 0.1.0

一个 [DeepSeek Harness（dsh）](https://github.com/deepseek-ai/DeepSeek-Harness) 插件。

你给它一句想法。它会在四个地方停下来先问你。然后用你自己 `assets` 文件夹里的素材，
出一条带 AI 旁白和硬字幕的视频。

横屏 16:9 给 YouTube 和 B 站，竖屏 9:16 给 TikTok 和 Shorts。

## 状态：很早期

装之前请先读这一节。0.1.0 **只做完了第一个里程碑**。

**现在能用的**

- 念一句话，把音频前后的静音裁掉，量出它的真实长度。
- 把你自己的一段素材裁到刚好那么长，混进旁白，再把这句话烧到画面上。
- 一个工作文件，每个阶段都读它写它，但一个阶段只能写自己那一节。写别人的节会
  当场报错。
- 自带一个不需要 API 密钥的语音引擎，还有一份命令行契约——换引擎只改配置，
  不用改代码。
- 素材文件夹入库：递归扫描（跟随软链接，所以放在外置硬盘上的素材也找得到），
  从七个地方读你写的描述和标签，只对指纹变了的素材去问理解那一步。
  一个坏素材不会拖垮整次入库。

**还不能用的**

- 没有"给一句想法就出视频"的命令。现在工作文件要你手写。
- 理解那一步是一个插入点，还没接到真的实现上，所以每条描述里机器写的那一半是
  占位文字。你自己写的描述和标签是真的，而且已经在用了。
- 写文稿、画面对应表、四个停点，还没做。
- 插件还没接进 dsh。

如果你今天就要一个能用的工具，去看下面 [已有的同类项目](#已有的同类项目)。
等这个到 1.0 再回来。

## 隐私：请先读这一节

自带的语音引擎**会把你的旁白文字发到微软的服务器**。

| 什么 | 数据去哪里 | 怎么避免 |
| --- | --- | --- |
| 自带语音引擎（默认） | 你的旁白文字会通过 [`node-edge-tts`](https://www.npmjs.com/package/node-edge-tts) 发给微软 Edge 的在线朗读服务。不需要账号，也不需要 API 密钥。 | 换成本地引擎，见 [换语音引擎](#换语音引擎)。 |
| 你的素材 | 不出你的机器。所有裁剪和编码都是本地 `ffmpeg` 做的。 | 不用做什么。 |
| 你的成片 | 不会上传到任何地方。这个插件不碰你的任何平台账号。 | 不用做什么。 |

自带引擎用的不是微软的官方公开接口，所以它随时可能停止工作。这正是把引擎做成
可替换契约、而不是写死在代码里的原因。

## 这个插件会往你的素材文件夹里写什么

每段素材旁边写一个 `<素材名去掉扩展名>.json`。`bench.mp4` 对应的就是同一个文件夹里的
`bench.json`。

**如果那个名字的文件已经存在，本插件会更新它。** 素材站经常在每段素材旁边附一个元数据
json，那些元数据是有用的：插件会读它的 `title`、`description`、`tags` 和 `search_term`
并用起来。然后把自己的键加进同一个文件——`schema`、`clip`、`fingerprint`、`fromYou`、
`fromMachine`。**不是它创建的键，一个都不动。**

动一个不是它写的文件之前，它会先存一份 `<名字>.json.bak`，只存一次。所以原文永远拿得回来。

有一件事你该知道。如果生成那个 json 的工具以后重写了这个文件，可能会把插件的键一起抹掉。
机器算出来的东西重算一遍就行，不算真的丢。但**你自己**写在那个文件里的内容会没了。想长期
留住的手写内容，放到同名的 `.narrate.txt` 里——见下一节。

素材文件夹里别的地方它都不写，素材本身它永远不改。

## 怎么给素材写描述

下面哪种顺手用哪种，插件会把它们收拢成同一种格式。描述取最明确的那个来源；标签把所有
来源合起来。

| 优先级 | 你在哪写 | 怎么写 |
| --- | --- | --- |
| 1（最高） | 直接跟插件说 | "那段机柜是我自己拍的，版权干净" |
| 2 | 手改 `bench.json` | 改文件里的 `fromYou` |
| 3 | 素材旁边的文本文件 | `bench.mp4.narrate.txt`——第一行是描述，`#` 开头的行是标签，其余进备注 |
| 4 | 表格 | 素材文件夹根目录的 `clips.csv`：文件名、描述、标签（用 `;` 隔开） |
| 5 | 素材旁边本来就有的 json | 下载来源写进去的那些内容 |
| 6 | 文件名 | `服务器机柜-特写_夜景.mp4` 按 `-`、`_`、空格切成标签 |
| 7（最低） | 文件夹名 | `assets/机房/bench.mp4` 得到标签 `机房` |

两件值得知道的事：

- **备注永远不被解析。** 你写"别用在商单里，客户不让露那个机柜编号"，插件一字不动地留着，
  并在写文稿和挑素材时交给模型看。它绝不试图去理解那句话的意思。
- **你的修改不会丢。** 插件记着自己上一次推导出来的值，所以能分清哪句是你写的、哪句是它
  自己上一版的输出。它自己的可以重写，你的会保住。真的换掉了自己的旧输出时，它会说出来，
  不让那句话不声不响消失。


## 需要什么

- Node.js 20 或更新。
- `PATH` 里有 `ffmpeg` 和 `ffprobe`。用 `ffmpeg -version` 检查。
  如果装在别处，设 `DSH_FFMPEG_PATH` 和 `DSH_FFPROBE_PATH`。
- 至少一个覆盖你写作语言的字体。中文请装 `fonts-noto-cjk` 或任何一个中日韩字体。
  没有字体，每一条字幕都会渲染成空方块。

## 安装

```sh
npm install dsh-narrate
```

**0.1.0 是一个普通的 npm 库，还不是 dsh bundle。** 它故意不在 `package.json` 里声明
`dsh.bundle`，因为挂载部分还没做，而一个 patch 文件缺失的 bundle 会让整个 dsh profile
启动不起来。挂载会在做完插件的那个里程碑一起交付。

## 它以后会怎么工作

五个阶段，四个停下来等你的地方。

| 停点 | 什么时候 | 你看到什么 | 你做什么 |
| --- | --- | --- | --- |
| 1 | 写文稿之前 | 至少三个问题：视频多长、给谁看、什么语气、最想让人记住哪一句 | 回答 |
| 2 | 文稿写完 | 完整文稿，一行一句，带编号 | 确认或修改 |
| 3 | 生成任何音频之前 | 画面对应表，加上**没有合适素材**的那些句子的清单 | 补素材、改对应表，或者点头继续 |
| 4 | 渲染之前 | 一个纯音频文件：只有旁白，没有画面 | 听语速，确认或重配某几句 |

没有你明确的"继续"，一个停点都过不去。这就是这个插件存在的意义。别的工具一口气
做完，只把结果给你看。

每个阶段都是读一个文件、写一个文件，所以没有黑箱，任何一步都能单独重做。画面长度
永远跟着音频的真实长度走，不会反过来——声音保持自然语速。

## 换语音引擎

语音引擎是**一条命令**，不是一段你必须用 JavaScript 写的插件代码。它读一个文本
文件，写一个音频文件。任何语言都能实现。

命令模板里的占位符：

| 占位符 | 换成什么 |
| --- | --- |
| `%TEXT_FILE%` | 一个 UTF-8 文件的绝对路径，里面是要念的那一句话 |
| `%OUT_FILE%` | 引擎必须把音频写到这个绝对路径 |
| `%LANG%` | 语言代码，例如 `zh` 或 `en` |
| `%VOICE%` | 音色名，原样传给引擎自己解释 |

```yaml
voice:
  command: ["my-tts", "--in", "%TEXT_FILE%", "--out", "%OUT_FILE%", "--lang", "%LANG%"]
  timeoutMs: 60000
```

你的引擎必须做到：

1. 成功时退出码 `0`，并且真的把 `%OUT_FILE%` 写出来。
2. 失败时退出码非 0，原因写到 `stderr`。
3. 只写 `%OUT_FILE%`，绝不修改输入文件。
4. 绝不要交互输入。
5. 输出的音频，`ffprobe` 能读出长度。

文本通过文件传，绝不通过命令行参数传，而且每个参数都作为独立的一项交给进程。
文稿是模型生成的文字，绝不能让它有机会碰到 shell。

完整契约（包括每一个错误名）在
[`docs/crew/api/voice-engine.md`](docs/crew/api/voice-engine.md)。

## 已有的同类项目

有好几个项目今天就能把整件事做完。它们都不会停下来先问你，而这正是这个插件唯一
要做的事。

- [OpenCut-AI](https://github.com/Ekaanth/OpenCut-AI) —— 用视觉相似度把文稿每一段
  匹配到你自己的素材库，全本地跑。
- [OpenMontage](https://github.com/Open-Montage/OpenMontage) —— agent 驱动的视频
  制作系统，很多流水线和工具。
- [NarratoAI](https://github.com/linyqh/NarratoAI) —— 影视解说专用，写稿到配音
  到字幕一条龙。
- [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) —— 一个主题
  或关键词出短视频，主要用网络素材库。

这个插件的原则是复用而不是重写：[`dsh-ffmpeg`](https://github.com/STARDUSTLC666/dsh-ffmpeg)
做视频处理，[`dsh-video-understand`](https://github.com/ilps2/dsh-video-understand)
把素材在本地变成文字，`node-edge-tts` 当默认语音。
